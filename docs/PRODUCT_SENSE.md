# PRODUCT_SENSE.md

Verified on 2026-03-07.

## Primary Users

- readers who want one-shot chapter downloads
- operators running long-lived monitoring on a server or NAS
- maintainers adapting to constant upstream source drift

## What Users Pay For

- reliable chapter acquisition
- simple setup
- predictable file output
- broad source coverage

## Priority Order

1. download correctness
2. source compatibility
3. operational clarity in monitor mode
4. release/install simplicity
5. new source breadth

## Tradeoff Rules

- choose durability over flashy features
- do not hide source-specific constraints from the user
- avoid complexity that makes adapter drift harder to fix
