# Go 1.27 Modernization

## Problem

Mangarr targets Go 1.26.6 while its supported build environment now has Go
1.27. The Modern Go Guidelines audit also found small uses of older standard
library patterns.

## Scope

- Raise the module and container builder to Go 1.27.0.
- Update the source-build requirement.
- Replace `github.com/google/uuid` with the Go 1.27 `uuid` package.
- Use `URL.Clone`, `errors.AsType`, `t.Context`, iterator collection, typed
  slice sorting, and `slices.Backward` where the audit found direct matches.
- Remove the obsolete UUID dependency and verify module files.

## Non-Goals

- Migrate existing code to `encoding/json/v2`.
- Rewrite generated protobuf code.
- Apply guidelines without a concrete matching code site.
- Change runtime behavior.

## Decisions

- Pin the builder to `golang:1.27.0-alpine3.23`, which is available for every
  configured release architecture.
- Keep this work separate from the Comix repair as a stacked PR.
- Preserve existing JSON behavior because the guideline only recommends
  `encoding/json/v2` for new code unless migration is explicitly requested.

## Progress

- Confirmed the Go 1.27 guideline set and relevant code sites.
- Confirmed the official multi-architecture builder image.
- Raised the module, builder image, and source-build documentation to Go
  1.27.0.
- Applied the relevant standard-library modernizations and removed
  `github.com/google/uuid`.
- Completed the repository verification gates.

- `go mod tidy -diff`
- `go fix -diff ./...`

The official Go 1.27.0 Alpine image manifest includes all configured release
architectures. A local container build was not possible because the Docker
daemon was not running.
